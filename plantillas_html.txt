PLANTILLA 2 - Formulario simple (un campo de texto y uno numerico)
Usalo para "crear un formulario que permita agregar/registrar X"
------------------------------------------------------------------------

<!DOCTYPE html>
<html lang="es">
<head><meta charset="UTF-8"><title>Formulario</title></head>
<body>
    <h1><!-- TODO: ej "Agregar dispositivo" --></h1>

    <!-- TODO: action debe ser la ruta del servlet que procesa el formulario -->
    <!-- method="post" porque este formulario CREA/MODIFICA algo -->
    <form method="post" action="RUTA_DEL_SERVLET">

        <label>Campo texto:</label>
        <!-- TODO: "name" debe coincidir con el req.getParameter("...") del servlet -->
        <input type="text" name="campoTexto" required><br>

        <label>Campo numerico:</label>
        <input type="number" name="campoNumero" required><br>

        <label>Campo decimal:</label>
        <input type="number" step="any" name="campoDecimal" required><br>

        <button type="submit">Enviar</button>
    </form>
</body>
</html>

PLANTILLA 3 - Formulario con varios tipos de input (texto, numero, select,
checkbox, fecha) por si el enunciado pide una entidad con muchos campos
------------------------------------------------------------------------

<!DOCTYPE html>
<html lang="es">
<head><meta charset="UTF-8"><title>Formulario completo</title></head>
<body>
    <h1>Registrar <!-- TODO: nombre de la entidad --></h1>

    <form method="post" action="RUTA_DEL_SERVLET">

        <label>Nombre:</label>
        <input type="text" name="nombre" required><br>

        <label>Cantidad:</label>
        <input type="number" name="cantidad" min="0" required><br>

        <label>Valor:</label>
        <input type="number" step="any" name="valor" required><br>

        <!-- select para elegir entre opciones fijas, ej: tipo de sensor -->
        <label>Tipo:</label>
        <select name="tipo">
            <option value="OPCION_1"><!-- TODO: texto visible --></option>
            <option value="OPCION_2"></option>
        </select><br>

        <!-- checkbox para valores booleanos, ej: "activo" -->
        <label>Activo:</label>
        <input type="checkbox" name="activo" value="true"><br>

        <!-- campo oculto: util cuando editas algo existente y necesitas mandar el id -->
        <input type="hidden" name="id" value="ID_ACTUAL">

        <button type="submit">Guardar</button>
    </form>
</body>
</html>

------------------------------------------------------------------------
NOTAS RAPIDAS
------------------------------------------------------------------------
- <a href="..."> siempre dispara GET (para navegar / consultar)
- <form method="post"> dispara POST (para crear / modificar / enviar datos)
- El "name" de cada <input> DEBE coincidir exacto con el
  req.getParameter("nombre") que lea el Servlet correspondiente
- El "action" del form y el "href" de los links DEBEN coincidir exacto
  con el @WebServlet("/ruta") del servlet que los debe atender
- input type="number" -> valida solo numeros enteros en el navegador
- input type="number" step="any" -> permite decimales
- required -> el navegador no deja enviar el form si el campo esta vacio
